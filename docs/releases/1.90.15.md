# Release checklist: 1.90.15

Filled in 2026-11-21 for `v1.90.15`, from `docs/release-checklist.md`. 1.90.15 completes
milestones 1.90.7 to 1.90.15 together, so there are no 1.90.7 to 1.90.14 releases. Those
milestones hold the 2026-11-21 audits: Claude's audit of main and Codex's readiness audit of
1.90.6. Their fixes landed in one batch, after 1.90.6. Results are **pass**, **skip** (with why)
or **fail** (with its issue).

## CI on the release commit

- **pass** `check`: green on the batch's pull request and on the release commit.
- **skip** `nightly`: started on the release commit after the tag. A failure there gets an issue
  in the next milestone.
- **skip** `opencode`: its daily run covers the newest OpenCode. The trial below ran this batch's
  OpenCode changes (#644, #658, #661, #675) against OpenCode 2.3.2.
- **pass** `chat`: the browser test passed in WebKit and Chromium on the batch.
