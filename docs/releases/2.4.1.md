# Release checklist: 2.4.1

Filled 2026-11-28 for `v2.4.1`, from `docs/release-checklist.md`; cut on a green `check` (the nightly
and the newest-OpenCode run started on it, not waited on).

2.4.1 is #1652's second part: each role learns from its own results. A role of the user's own was
ranked by the GPU router on the record of the built-in it "worked as", so a sound-effects role set
to work as writing got the model best at prose, and its results moved the writing role's ranking.
Now a user's role is ranked and tuned on its own results alone; until it has some, every model
starts even, as for a new built-in. The built-ins learn as before: writing on its own record,
the coding roles on their size's.

2.4.1 also fixes `wb run amend --skip`'s line: when the run's driver stopped the skipped
stage's running item first, the amend said none of its items was running.
