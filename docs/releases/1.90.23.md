# Release checklist: 1.90.23

Filled in 2026-11-21 for `v1.90.23`, from `docs/release-checklist.md`. 1.90.23 completes
milestones 1.90.17 to 1.90.23 together, so there are no 1.90.17 to 1.90.22 releases. Those
milestones hold the second 2026-11-21 audit of main (a8e5298): 74 issues, 72 fixed and 2 fixed
in part (#799, #812, which continue in 1.90.24). Results are **pass**, **skip** (with why) or
**fail** (with its issue).

## CI on the release commit

- **pass** `check`: green on the batch's pull request.
- **skip** `nightly`: started on the release commit after the tag. Its macOS job is the first
  real run of several fixes (#848's ps time zone, #852's APFS space through CoreFoundation, #773
  without Landlock). A failure there gets an issue in the next milestone.
- **skip** `opencode`: nothing here changes how OpenCode is invoked or read. #774 reads the step
  tokens the runner already reads; `tests/fake_opencode.py` gained a mid-round compaction.
- **pass** `chat`: the browser test passed in WebKit and Chromium on the batch.
