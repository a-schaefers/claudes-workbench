# Release checklist: 1.90.3

Filled in 2026-11-21 for `v1.90.3`, from `docs/release-checklist.md`. 1.90.3 completes milestones
1.90.2 and 1.90.3 together, so there is no 1.90.2 release. The fixes from the audits of v1.8 and
v1.90 landed in one batch (#632), which also carries most of milestones 1.90.4–1.90.6; those
milestones stay open for what's left. Results are **pass**, **skip** (with why) or **fail** (with
its issue).

## CI on the release commit

- **pass** `check`: green on the batch's pull request (#632) and on the release pull request.
- **skip** `nightly`: started on the release commit after the tag. A failure there gets an issue
  in the next milestone.
- **skip** `opencode`: its daily run covers the newest OpenCode. How OpenCode is run and read
  changed (#427, #438, #440, #519), and that is covered by the real-OpenCode tests `check` runs
  and by the one real run below.
- **pass** `chat`: the browser test passed in WebKit and Chromium on the web chat's changes in the
  batch (#536, #539).

## What the README offers
