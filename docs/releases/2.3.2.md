# Release checklist: 2.3.2

Filled 2026-11-28 for `v2.3.2`, from `docs/release-checklist.md`; cut on a green `check` (the owner's
rule since 2.3: the nightly and the newest-OpenCode run are started on it, not waited on).

2.3.2 fixes four races that failed CI's runs now and then (`check` on 2.3.1's own commit, the WSL
nightly, the newest-OpenCode run), each at its cause, and three of them were users' bugs too:

- A model thinking beside a job it left running in the background was not stopped: a command
  still starting (in wb's shell shim) when its shell call returned was taken for a new command in
  the foreground, and the think guard waited on it.
- On a machine with podman installed but never used, every GPU check asked podman about an Ollama
  container, and a first `podman ps` builds its storage, which takes seconds; now podman is asked
  only where it keeps something for the user.
- A review, `wb verify` or `wb shot` could miss an edit made in the same instant as git last wrote
  the worktree's index, a same-sized file read as unchanged: the scratch index now keeps the index's
  timestamp, so git checks that file's contents.
- The test suite no longer runs wb's update check against the network (the newest-OpenCode run
  fetched its own checkout).

Results are **pass**, **skip** (with why) or **fail** (with its issue).
