# Release checklist: 1.90.1

Filled in 2026-11-20 for `v1.90.1`, from `docs/release-checklist.md`. Milestone 1.90.1: the
blockers from the audits of v1.8 and v1.90 (#416–#422, #490–#495), and the audio follow-ups
(#397, #398). Main also carried the first fixes from milestones 1.90.2–1.90.6 when this was cut;
they ship here too, and their milestones stay open for what's left. Results are **pass**,
**skip** (with why) or **fail** (with its issue).

## CI on the release commit

- **pass** `check`: green on each change's pull request and on the release pull request.
- **skip** `nightly`: not waited for. Started on the release commit after the tag; a failure
  there gets an issue in 1.90.2.
- **skip** `opencode`: its daily run covers the newest OpenCode. What changed in how OpenCode is
  read and configured (#491) is covered by the real-OpenCode tests `check` runs.
- **pass** `chat`: the browser test (`browsers`, WebKit and Chromium) passed on the pull
  requests that changed the web chat: the audio player (#616) and its bind and host checks (#629).

## What the README offers

- **pass** Each command the README offers answers `bin/wb <command> --help` at the release
  commit: setup, try, start, audio, image, top, stats, chat, doctor, experiment.

## Models and long runs

All **skip** for 1.90.1: not run by hand beyond the one trial above. The GPU, Ollama and
hardware changes are tested against fake sysfs trees, a fake `nvidia-smi` and patched commands;
Jetson, DGX Spark, macOS's GPU view and WSL's registry read need a real machine. The web chat
behind a real `tailscale serve` (#448) wasn't run: it would change the developer's tailnet.
