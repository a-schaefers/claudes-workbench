# Release checklist: 1.91

Filled in 2026-11-21 for `v1.91`, from `docs/release-checklist.md`. 1.91 brings the Workbench
pane a face and a voice of its own, and fixes what a bar-gated audit of 1.90.31 found.

The pane now opens with an animation: the apprentice at the forge, then Claude's Workbench in
large colour lettering, which lands in a coral modeline under the tabs (#962, #963). The
animation plays again after `/workbench-quit` and a new `/workbench`. It survives the dock's
first redraw, which comes a row shorter: that redraw read as a resize, so the animation ended
before it was seen. The modeline says what the agents are doing now, each open task's name,
round and phase, and scrolls like a ticker when the line is longer than the bar (#976). It is
drawn from the task files the pane already reads, so it costs Claude nothing. `wb update
--check` and `wb doctor` now say when Claude Code is running an older copy of the mod than the
clone holds, and `wb update` refreshes it (#977): a clone pulled with git left the plugin cache
behind, and the new pane never showed.

The audit took only what meets its bar: lost work, false results, a blocked core path, or an
action nobody asked for. Each finding needed a refuter and a judge who saw only the bar (#958).
It found:
- a file the agent wrote under a path the repo's `.gitignore` matches (`lib/` in GitHub's
  Python.gitignore) was in no diff and no commit, then deleted with the worktree at accept while
  the tests read PASS. The review now names such files, and `wb accept` and `wb next` refuse to
  commit until `--include` adds them (#983);
- editing a refused web chat message replaced the draft being typed (#960);
- `wb next` recorded one compaction against both steps (#965);
- `wb start` overwrote the router's reason, so `wb watch` showed an empty "routed:" (#971);
- a failed OpenCode compaction ("Compaction produced no summary") failed the task; it now hands
  over to a fresh session (#969);
- a permission prompt answered at the terminal still went to the phone: away is now judged by
  the device last used (#959).

Also here: the probe experiment's levels, read cap and round-1 outline (#857, still opt-in), the
bench replays' git inside the lane (#858), the Stats tab's height, and the nightly's test fixes
for macOS and WSL2 (#961, #972, #973), with CI's check and the nightly in shards (#980, #982).

Results are **pass**, **skip** (with why) or **fail** (with its issue).
