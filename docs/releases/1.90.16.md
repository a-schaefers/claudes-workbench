# Release checklist: 1.90.16

Filled in 2026-11-21 for `v1.90.16`, from `docs/release-checklist.md`. 1.90.16 holds the four
follow-ups that 1.90.15 fixed only in part: the chat's event stream sends only what changed
(#755), `wb image` speaks ComfyUI and `wb scout` names an image server already running (#753),
an image or audio engine can be pinned to one card (#752), and Ollama for Windows seen from
WSL2 takes this machine's GPU turn (#750). It also gives CI's suite jobs 40 minutes. Results
are **pass**, **skip** (with why) or **fail** (with its issue).

## CI on the release commit

- **pass** `check`: green on the batch's pull request.
- **skip** `nightly`: started on the release commit after the tag. A failure there gets an issue
  in the next milestone.
- **skip** `opencode`: nothing here changes how OpenCode is invoked or read.
- **pass** `chat`: the browser test passed in WebKit and Chromium on the batch, including the
  new check that a settled plan arrives cut and "Show the whole plan" fetches the rest (#755).

## What the README offers

- **pass** Each command the README offers answers `bin/wb <command> --help` at the release
  commit: setup, try, start, audio, image, top, stats, chat, doctor, experiment.

## By hand, on real machines

The machine for every run below: Arch Linux on kernel 7.2.14, an ext4 home, Python 3.14.10,
git 2.56.1, OpenCode 2.3.2, Claude Code 2.1.323, Landlock ABI 10, a 16 GB AMD card.

## Models and long runs

All **skip** for 1.90.16:
- A real ComfyUI and a real Forge (#753) are tested against fake HTTP servers.
- An engine pinned to one card (#752) needs a two-card machine; it is tested against fake
  servers and a fake GPU.
- Since #750, on WSL2 a task on a server on the Windows host takes turns with WSL's own tasks
  and engines; `"same_gpu": false` in models.json gives the old behaviour.
