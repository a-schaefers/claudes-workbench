# Release checklist: 1.90.6

Filled in 2026-11-20 for `v1.90.6`, from `docs/release-checklist.md`. 1.90.6 completes milestones
1.90.4, 1.90.5 and 1.90.6 together, so there is no 1.90.4 or 1.90.5 release. Their fixes landed in
one batch, after the first batch shipped in 1.90.3. Results are **pass**, **skip** (with why) or
**fail** (with its issue).

## CI on the release commit

- **pass** `check`: green on the batch's pull request and on the release commit.
- **skip** `nightly`: started on the release commit after the tag. A failure there gets an issue
  in the next milestone.
- **skip** `opencode`: its daily run covers the newest OpenCode. Nothing in this batch changes
  how OpenCode is run or read.
- **pass** `chat`: the browser test passed in WebKit and Chromium on the web chat's attachments
  (#623).

## What the README offers

- **pass** Each command the README offers answers `bin/wb <command> --help` at the release
  commit: setup, try, start, audio, image, top, stats, chat, doctor, experiment.
