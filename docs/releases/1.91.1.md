# Release checklist: 1.91.1

Filled in 2026-11-22 for `v1.91.1`, from `docs/release-checklist.md`. 1.91.1 widens what the
agent's shell may run, hides more of what it must not read, and settles the probe experiment.

The agent runs a much wider toolset now (#994, #995, #1000, #999): infrastructure as code
checked offline, local test services and emulators, more build systems and languages, docs,
shaders and embedded tools, more linters and test runners, and the Lisps and Schemes (#988).
A tool that sends usage data by default runs only with its opt-out written in the command
(`CDK_DISABLE_CLI_TELEMETRY=true cdk …`, `semgrep --metrics=off`, `nx --no-cloud`), and that
holds under every runner: `npx`, `pnpm exec`, `yarn`, `bun`, `uv run` and the tool's bin path
get the plain command's verdict (#999). Publishing, deploying, flashing hardware and a tool's
self-update are refused. The build tools' remote caches and remote execution are off for the
agent and its tests (`NX_SKIP_REMOTE_CACHE`, Pants's write and execution switches), and Bazel's
and Buck2's remote flags ask first. `--test` no longer lifts a subcommand limit (#995).

The agent's rules no longer ride in an environment string, so the allowlist can grow (#997):
they live only in the config layer, the project's own OpenCode config is switched off, and what
that switch also dropped (AGENTS.md, the project's skills, its config's instructions) is handed
back by workbench. A project `opencode.json` that allows everything lifts nothing.

The lane hides more credential files (#992, #998, #999): the Wrangler, Vercel, Supabase,
Netlify, Pulumi, Serverless, Terraform, Helm, Dart, Ansible Galaxy, Maven security, Foundry,
MinIO, Erlang cookie, MySQL login, dbt, OpenStack, Hetzner, Chef, Infracost, minikube, Firebase,
Semgrep and Rush logins, with the variables that point elsewhere. Semgrep, Helm and k6 get
settings files of the agent's own. The agent's SDKs skip the cloud metadata endpoint (#993:
AWS, Google), and `wb doctor` names a local daemon port that listens (Docker, adb, debug
probes).

The probe experiment's third A/B, 18 paired replays on one 27B model at a 40K window on a 16 GB
AMD card, found `on` no better than `off` (#996, #857 closed): probe stays opt-in and
unrecommended. Another model or card may differ; ARCHITECTURE.md (*Experiments*) has the
numbers and how to rerun it. The pane's option now reads "On (large files only)" (#991).

Also here: a project's compiler, typecheck or lint goes ahead of a task's tests (#988); a hung
test can't be swallowed into a pass (#986); a handover after a failed compaction no longer
crashes the runner on macOS (#985, #987); `ship.sh` retries a failed `gh pr view` (#989); and
SECRETS no longer names one user's own browser directory (#990).

Results are **pass**, **skip** (with why) or **fail** (with its issue).
